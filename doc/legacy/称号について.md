# 称号について

獲得条件の実体は `backend/gamification/services.py` にある。

- 画面に出す文言: `ACHIEVEMENT_DEFINITIONS` の `condition_text`
- 実際に付与する判定: `_check_achievement`
- 付与処理: `check_and_grant_achievement_titles`

`secret: True` の称号は、画面の条件文が「？？？」になる。数値そのものは判定関数に入っている。
`ultra_secret: True` の称号は、未獲得のあいだ名前も「？？？」になる。

付与のタイミングは、投稿・リアクション受信（`submissions/views.py`）、抽選（`lottery/services.py`）、記事公開（`articles/serializers.py`）である。条件を満たした未獲得の称号がまとめて付く。最初の1つは装着中の称号になる。

件数は、削除されていない自分の投稿に対するもの。時刻と曜日は日本時間。連続日数は、投稿した日が途切れずに続いた最長日数。
